# 集成到微信 Bot 的性格设置

此扩展随 `wechat-clawbot-windows` 一起加载，不注册第二个插件卡片、不建立第二个微信会话、不修改 DSH 本体。

在 DSH「插件 → 微信 Bot」展开现有卡片，顶部新增「性格与聊天风格」。开启「启用性格设置」后，下一次提示词组装即采用设置，不重启微信监听。默认关闭，升级不自动改变已有聊天风格。

可调整温柔伙伴、活泼朋友、安静陪伴、坦诚搭档、可靠助手五种预设，以及名字、用户称呼、亲近程度、闲聊长度、幽默程度、追问习惯和自定义说明。选择和开关即时保存，文字在离开输入框时保存。原有 emoji 开关负责最终文字过滤，性格设置不覆盖该开关。

「查看已保存的性格提示词」在浏览器本地执行与服务端相同的构建函数，显示实际注入的性格部分；不调用模型、不写入聊天历史、不发送微信。它不是示例回复或完整系统提示词，也不是模型行为的保证。

## 集成方式

- `choices.json`：界面选项和提示词使用的共同定义。
- `runtime.ts`：输入归一化和稳定的提示词构建，不带时间戳、随机值或网络访问。
- `schema.ts`：新增配置字段，全部纳入 clawbot 原有 schema、HOT_FIELDS 和即时更新机制。
- `client.js`：嵌入原卡片的 React 组件，沿用原有 configForms、快照订阅和逐字段重置。
- `integrate.mjs`：只对 `windows/.build/work` 生成副本添加接入代码；锚点变化即构建失败。

性格段落仅在配置的微信主会话注入；普通 DSH 会话和子代理不继承。配置仍由 DSH 保存到当前 profile 的 patch 中。关闭后不再注入性格部分，已发送的历史消息保留。

这版调整表达和相处方式，继续复用 DSH 的工具与审批能力。聊天追问不代表定时主动问候；近期经历数据库、跟进事项和自动联系未在此版本实现。语音不在本次范围内。

## 验证

在 `windows/` 运行 `npm test`。测试覆盖默认兼容、schema 与热字段、非法输入、微信会话隔离、实时修改和关闭、原有 emoji 策略、客户端加载和前后端提示词一致性，并执行 Windows 与 Codex 桥接回归。
