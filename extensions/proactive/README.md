# 随机主动互动与真实分享

`0.9.8-windows.7` 在原「微信 Bot」设置卡片中加入「主动互动与真实分享」。实现位于 `extensions/proactive/`，只在生成的构建副本中接入，原版源码保持不变。

每次重新抽取机会间隔，默认 90～240 分钟；只在北京时间 10:00～21:30 内考虑分享，免打扰结束后的机会也错开。机会不是必发通知：微信上下文不可用、会话忙、刚聊完、没有可靠内容、重复内容都会跳过。默认每天最多两份，评估次数最多四次；当天分享后没有得到回应，就暂停继续分享。重启不会补发错过的机会，也不会重试投递结果不确定的消息。

起步探索期可设 0～14 天（代码默认关闭），期间随机 45～90 分钟考虑一次，每天最多四份、最多六次评估，无回应仍暂停。起始时间持久化，重启不会延长；到期自动恢复常规间隔和上限。具体兴趣、地点和探索期在自己的 DSH 设置中填写，不随源码发布。

在同一页面可调整总开关、行业主题、常用地点、资讯/附近吃喝/旧话题、配图偏好、频率与免打扰时段。主题与地点代码默认为空，不猜用户所在城市或兴趣。地点用于检索真实门店信息，并非手机 GPS；当前使用 DSH 的联网工具，未接入专门的地图或外卖服务。

选题时要求模型结合真实聊天和 MemOS 中的反应：明确喜欢、深入追问可支持多选同类，明确拒绝的主题避开，礼貌回应不等同强兴趣。证据不足时换方向探索。偏好由现有 MemOS 的真实用户消息记录与模型理解处理，未另外实现评分模型或用沉默推断喜好。

分享用第一人称讲一个具体看法，通常一到三句。模型先检索和核对资讯，不写报告，不只丢链接；原文来源保存在互动记录里，必要时再附网址。可从原文获取实际照片或图表，经过格式与大小处理，交给支持图片的当前模型查看后，用微信原有加密上传通道投递图片与短评；无合适图或模型无法看图时退回文字。没有实现生成图片或语音。

只给当前绑定微信用户分享。后台指令使用独立的 producer source，不伪装用户来信、不记成用户经历、不插入正在进行的对话。主动轮次只允许读取资料/记忆、准备图片、分享或跳过，原有普通回复工具在此期间被暂停；真实用户来信优先。多个联系人仍共享原 clawbot 主会话，主动内容也可能引用该会话中的真实记忆，因此此功能按个人 Bot 使用，未提供联系人之间的记忆隔离。

状态与最近互动可在同一设置页查看。「查看分享规则（不发送）」只预览已保存的规则，不调用模型或发送微信。关闭总开关会取消尚未投递的机会；已经发出的消息不会撤回。

电脑和 DSH 需要保持运行，微信 context token 需要有效，联网工具需要可用。模型评估沿用 DSH 当前模型和 OAuth/API 配置，消耗相应额度。图片获取只支持公开 HTTP(S)，拒绝本地网络目标、不读取私人文件；不会为了截图调用浏览器或自动执行命令。

验证包括随机时段、上限/重复/失败持久化、用户优先、会话与工具隔离、接口认证、设置卡片和静默跳过。测试使用模拟投递，没有发送真实微信或调用付费模型；真实分享效果、图片投递与视觉界面仍需要日常使用验收。
